-- New: a page on the same origin, such as a dashboard, can call /api/v3 with the session cookie the sign-in set and no API key. The session is read as the pages read it, so switching the user off or changing their password ends the access on the next call; every method but GET and HEAD sends the session's token in an X-P202-CSRF header (GET /me answers it as auth.csrf_token), and a write without it is 403 and changes nothing. A request with an Authorization header is answered as before, by its key alone.
