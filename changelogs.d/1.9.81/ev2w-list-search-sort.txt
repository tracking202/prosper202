# EV2W: v3 lists take q, sort, sort_dir and multi-value filters.
-- New: The v3 lists of campaigns, trackers, landing pages, affiliate and traffic source networks, traffic source accounts, rotators, text ads, users and forecast events take q= (the record's name contains the text, in any case; a tracker is found by its campaign's name, a user by user name, first or last name or email), sort= with sort_dir=asc or desc (from each list's own fields, named in the OpenAPI file; ties ordered by the key so pages neither repeat nor skip a row), and several values for a whole-number filter separated by commas (filter[aff_network_id]=1,4). A sort the list does not offer, a sort_dir without a sort, a q on a list with no name to search, and an empty or spaced item in a filter's list are each a 422 naming the parameter. The rotator list, which ignored filter[...], now applies it or refuses it, and the user list takes the same parameters.
app: New: The API's lists can be searched by name, sorted by a field of your choice, and filtered by several ids at once.
