# HQ8N: click ids from 10,000,000,000 up are the hosted edge's.
-- Changed: Click ids from 10,000,000,000 up now belong to the hosted edge, so where a click was recorded can be read from its id alone. The install's own click counter never hands one out: if something has pushed 202_clicks_counter that far, the click is refused with an error that names the counter and how to set it back, rather than recorded under an id the edge may already have given another click. ClickId::isEdge() is the one place the boundary is tested, and a check in the test suite fails the build when anything but the click allocator writes the counter.
