-- New: `p202 tracker create-with-url --items` and `p202 tracker update --items` take a JSON list of up to 50 trackers, check every item before sending anything, and answer each one on its own (created, updated, staged, refused, unconfirmed or not sent), so 27 links and their text ads take two calls instead of 54. The MCP tools tracker_create_with_url and tracker_update take the same list as `items`. A failure that leaves a write unknown stops the items after it, and the partial-failure error names the items that were done, so they are not sent again.
-- Changed: An MCP tool call that ends as a partial failure now returns the command's answer beside the error, so the assistant sees which items were done.
