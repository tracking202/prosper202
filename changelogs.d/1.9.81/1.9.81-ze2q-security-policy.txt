-- New: SECURITY.md says how to report a vulnerability privately (GitHub's private vulnerability reporting), which versions get security fixes (the latest release), and what is in scope (the self-hosted app, both CLIs and the Go CLI's MCP server, the SDKs, the release zip and the Docker image); the release zip carries it beside README.md
-- New: Dependabot proposes Composer (composer.lock) and Go module (go-cli/) updates weekly, minor and patch releases grouped into one pull request per ecosystem, as it already did for GitHub Actions and the Docker base image. A new workflow, Dependency Audit, runs composer audit on composer.lock and govulncheck on the Go CLI on every pull request and landing, weekly and on demand. A pull request or landing that changes composer.json, composer.lock, go-cli/go.mod or go-cli/go.sum fails on an advisory, as do the weekly and on-demand runs; any other reports it as a warning and in the job summary, and passes. An audit that could not run is said to have not run, never passed: it fails where an advisory would, and warns elsewhere
