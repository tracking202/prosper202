# 4KFZ: one route for every outbound request, an egress-proxy setting with a test, and getData()/getUrl() held to the vendor host.
-- New: An egress proxy for servers that reach the internet only through one. An admin sets it on Account › Settings › Egress proxy: the proxy URL (http:// or https://, the host and the port), and under Advanced a user name and password, which are stored and never shown again (a Stored marker says they are there; an empty box keeps them; they can be removed). Test connection sends one request through the proxy typed in the form, without saving it, and says plainly whether it worked or why not (the proxy asked for a password, refused the tunnel, did not answer, replaced the certificate, or this server could not look up the host). define('P202_EGRESS_PROXY', 'http://proxy.example:3128'); in 202-config.php still works and overrides the saved one, which the page says. Everything this server sends out then goes through it: export and LTV webhooks, traffic-source postbacks, Slack notices, syncs, the conversion destinations (Google Ads, GA4, ChatGPT Ads), Get LP Code's Check my page, the GeoIP download, and the calls to my.tracking202.com, the licence check, ClickServer, the app stores, Google Play Integrity, IPQualityScore, exchange rates, Messaging, Chat Pass, the Landing Page Optimizer and the AI relay. The pinned senders refused every proxy, so on such a server none of them could be delivered. This server still looks up every host itself and checks the address: the proxy is asked for a CONNECT tunnel to that address, never to look up a name, and TLS is verified against the host name inside it, so a proxy that replaces certificates cannot carry these requests. Plain-http postbacks are tunnelled too, so the proxy must allow CONNECT to port 80 and any other port a postback URL names. An address only P202_WEBHOOK_ALLOW_NETWORKS admits, and a loopback override, are reached directly. A value that does not read as a proxy URL, or a saved one that cannot be read, holds all of them, naming the setting, and nothing is sent around the proxy instead: webhooks and postbacks wait and are retried. Every call to a fixed host now also reads at most 8 MB of its answer (the update download 400 MB).
app: New: An egress proxy on Account › Settings, with Test connection: everything this server sends out goes through it, still checked and pinned to the address it looked up.
-- Fixed: Security. getData() and getUrl(), which fetch the update feeds, the hosting partners list and the TV202 feed, followed every redirect to any host and any address. They now fetch only from https://my.tracking202.com, follow a redirect (at most 3) only to that host over https, never follow a POST's redirect, and read at most 8 MB of an answer; anything else is refused and logged without its query.
-- Fixed: Account › Settings failed with a server error, instead of saying so in its panel, when the GeoIP refresh row or the traffic source owners panel could not be read: the error replaced the page's escaping function. PageEscaperIsNotOverwrittenTest holds every page that names its escaper $e to never write $e again.
