-- New: Every v3 API error answer (each 4xx and 5xx) carries `code`, a stable name for what went wrong, beside the fields it already had: `version_conflict` for an update made on an older read, `name_taken`, `already_exists`, the three Idempotency-Key refusals, `invalid_json`, `upgrade_pending` when the database is behind the code, `write_committed`, the sync codes, and a code for each status otherwise. The list is `Api\V3\ErrorCode`, documented in docs/openapi.yaml's Errors section and the `Error` schema's enum; Bootstrap::jsonResponse() gives a body that names no code its status's code and replaces one the list does not hold, and ErrorCodesAreDocumentedTest and ErrorAnswersCarryACodeTest hold the list, the spec and the answers together. The Go CLI shows it as `api_code` in its --json error envelope and reads `upgrade_pending` for its upgrade hint.
