# XT9N: every cell of the tab-separated downloads through one cell function.
-- Fixed: The Visitors download, the Analyze downloads (keywords, referers, variables and the rest), the Group Overview download and the Publishers download write every cell through one function (Prosper202\Report\TsvCell). A tab or a line break in a keyword, referer, landing URL, c1-c4, UTM or custom variable value is written as a space, where it used to move every column after it or start a new row; a text cell beginning with =, +, - or @ gets a leading apostrophe so a spreadsheet shows it rather than running it as a formula (numbers, percentages and amounts are left as they are). The Visitors download no longer writes HTML entities: a referer or cloaked link with & in it reads as it was sent, not as &amp;. TsvCellTest refuses a tab field separator written anywhere else.
app: Fixed: A tab or a line break in a keyword, referer or other visitor value no longer moves the columns of the Visitors, Analyze and Group Overview downloads, and a value starting with = or + is no longer run as a formula.
