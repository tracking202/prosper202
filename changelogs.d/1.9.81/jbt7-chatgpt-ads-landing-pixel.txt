-- New: A simple landing page can load OpenAI's ChatGPT Ads pixel. Add a "ChatGPT Ads Pixel" to the traffic source (its code is the pixel id; OpenAI's base code or image tag pasted whole is taken and only the id kept) and switch the pixel on under Setup › Landing Pages. The page loads it for that source's visits on the Bot202 Facebook Pixel Assistant's privacy and consent terms, keeps the pixel's __obref browser reference with the click (removed when the visitor withdraws consent), and a ChatGPT Ads destination sends it as user.obref with hashed email and phone. A conversion recorded in the browser fires the pixel's event under the event type and id the destination sends, so OpenAI counts it once, and a rotator sending the visit to your own page passes the ad's oppref on. The API, p202 ppc-account pixel (--type-id 7) and the MCP pixel tools take the new type; the 1.9.81 upgrade adds it. A page with a Content-Security-Policy must allow OpenAI's hosts (documentation/features/chatgpt-ads.md, step 4).
