# 1HKV: MysqlUserRepository::create() under a strict sql_mode.
-- Fixed: MysqlUserRepository::create() left user_dash_email, install_hash and user_hash out of the user row, each NOT NULL with no default, so under a strict sql_mode (the API's connection) the insert was refused. No served code calls it yet. It now names them with the values POST /users gives (the dash email is the account email, install_hash the install's, user_hash empty) and gives the new user a publisher id as POST /users and Settings › Users do. Settings › Users now writes the dash email for a user it adds too, so every path that makes an account makes a row a strict sql_mode accepts.
