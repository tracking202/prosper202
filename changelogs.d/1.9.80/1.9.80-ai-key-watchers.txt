-- New: My Account › Personal Settings › API keys lists, under each key an AI app connected through Tracking202's MCP server (https://mcp.tracking202.com), the campaign watchers that keep reading with that key after the chat ends: the campaign, what it watches in plain words, its status, when it ends, its alerts and the latest one, with a Stop button for each running watcher. Revoking such a key, deleting it with DELETE /api/v3/users/{id}/api-keys/{key}, an app giving its key back with POST /api/v3/connect/revoke, and deleting the user each ask the MCP server to stop the key's watchers first. That is best effort: the key is deleted whether or not the server answers, a deleted key reads nothing more, and the page says so when the server did not confirm it. The install waits at most 3 seconds for the server, never follows a redirect, sends a token derived one-way from the key rather than the key itself, and shows "couldn't load watchers right now" when the server is down. Accounts with no AI connection make no call.
