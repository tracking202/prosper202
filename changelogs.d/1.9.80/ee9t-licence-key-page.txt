-- Fixed: The license-key page (api-key-required.php) no longer lets a visitor replace the install's saved license key. It answers with nobody signed in, and its form token is one every visitor holds, so any key Tracking202 accepted replaced the saved one, and whoever held that key could later revoke it and lock the install. While no key is saved the page works as before (the install flow). Once one is saved, replacing it needs a signed-in session whose user can change Settings, or the username and password of such a user entered on the form; a wrong password is refused and counted by the sign-in page's throttle, and Tracking202 is not asked about the posted key until the owner is shown. The sign-in itself needs no license, so an owner whose key expired can still sign in and replace it. The page also no longer shows the first 8 and last 4 characters of a saved key that does not validate; it says only that a key is saved.
app: Fixed: Only a signed-in admin, or someone who enters an admin's password, can replace the install's saved license key on the license-key page, and the page no longer shows part of the saved key.
