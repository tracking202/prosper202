-- Changed: The Prosper202 CLI (`p202`, `p202 shell` and `p202 mcp`) and connecting an AI assistant through Tracking202's MCP server no longer need a paid Prosper202 ClickServer subscription or trial: an active free ClickServer licence is enough, that is an install ClickServer key that my.tracking202.com answers as valid, paid or not. The Go CLI's 402 (category licence) and the connection's refusal now come only for a key Tracking202 does not accept (one it does not know, or, for accounts made since October 2026, one whose account has no CPM* newsletter subscription), and say what to do; the 30-day grace period while Tracking202 cannot be reached reads the key's last valid answer, the one the web sign-in records. /capabilities reports the same verdict as `cli` and `shell`. POST /connect/token answers an install with no ClickServer key with a 402 licence refusal, and one whose key cannot be read connects without `licence_key_sha256` instead of answering 500. `p202 shell` no longer refuses on its own when `shell` is false: the install's licence gate answers each command, with its hint.
