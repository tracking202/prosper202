-- New: Setup › Traffic Sources has an Add ChatGPT Ads button: one click makes the ChatGPT Ads traffic source, an account on it and the campaign_id={campaign_id} and ad_id={ad_id} variables Ads Manager fills in. Pressed again it makes no second source; it only adds back an account or variable the source is missing, and leaves what you changed. Get Links, for a link on that source, gives the destination URL and the tracking template to paste into Ads Manager (utm_source=chatgpt, the campaign and ad ids, and ChatGPT's click id oppref; on a landing page also t202id and t202kw). GET /api/v3/trackers/{id}/url answers the same pair as chatgpt_ads, POST /api/v3/ppc-networks/chatgpt-ads is the button, and the CLI has p202 ppc-network add-chatgpt-ads. A source you already named ChatGPT Ads (the only one of that name) becomes the ChatGPT Ads source instead of gaining a twin. Get Links' list of saved links gives a ChatGPT Ads link the same two values. The upgrade adds ppc_network_platform to 202_ppc_networks, which marks the ChatGPT Ads source; the API reads and writes it, and p202 sync and import carry it to another install. The MCP connector has an Add ChatGPT Ads tool, and tracker_get_url returns the pair.
