# 974K: Slack notices go to the account's own webhook
-- Fixed: Slack notices about changes on an account (a campaign, landing page, text ad, traffic source, tracking link or redirector added, changed or removed, a key or setting changed on Account, Administration, API integrations or User management) were sent to the webhook saved on the install's first account, whichever account made the change, and the webhook an account saved under Account › API integrations was never used. Each account's notices now go to its own saved Slack incoming webhook, and an account that has not saved one sends none. Install-wide notices, such as old click data being cleared by the cron job, still go to the first account's webhook.
app: Fixed: Slack notices go to your own account's webhook, not the install owner's.
