-- New: Setup › Destinations › ChatGPT Ads connects a ChatGPT Ads (OpenAI Ads) account with one Advertiser API key. Prosper202 checks the key with OpenAI before storing it and fills in the ad account's name, currency and time zone; a key OpenAI refuses, or one that could not be checked, is not stored. When OpenAI cannot be reached or is limiting requests, the page and the CLI say so and to try again in a minute, never that the key is wrong; over the API that is a 503 or 429 with Retry-After (502 for an answer that cannot be used), never a 422. Run setup then finds or creates the account's web pixel, creates a Conversions API key, creates the ChatGPT Ads destination when this version has it, and creates one event setting per event type with a 30-day click window. Each step is shown and can be skipped, and setup can be run again without making anything twice. Where OpenAI has pixel or key creation switched off for an account, setup says so and takes the pixel id and key from Ads Manager instead. Replace key, under a connection, takes a new Advertiser API key for the same ad account. Keys are stored encrypted and never shown, served or logged. Over the API, `POST /api/v3/destinations/{id}/test` sends a real, counted test event only with `"real": true, "confirm_counted": true` (`p202 destination test --real` sends both). The same from a script: `p202 ad-connection list|get|create|update|check|setup|delete` and `/api/v3/ad-connections` (scope `ad-connections`).
