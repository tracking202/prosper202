# SL7T: ChatGPT Ads spend goes only to clicks of the account's ChatGPT Ads traffic source.
-- Changed: On an account with a traffic source marked as ChatGPT Ads (202_ppc_networks.ppc_network_platform chatgpt_ads, set by Setup › Traffic Sources › Add ChatGPT Ads), ChatGPT Ads spend in the spend ledger (platform openai_ads) is shared only over that source's clicks, in the reports, the report pages and GET /api/v3/spend-ledger, so a click of another traffic source that carries the same ad id keeps its CPC instead of taking a share. An account with no marked source, such as one whose ChatGPT Ads source was set up by hand, is matched by the ad id alone, as spend of every other platform is. A removed marked source still marks the account. Where the tie decided something in a report's window, its spend_ledger says so in tie_note, and the report pages show the same sentence. Setup › Traffic Sources marks or clears any source as ChatGPT Ads on its edit form (under Advanced), so a ChatGPT Ads source set up by hand under another name can be marked too; after Add ChatGPT Ads, the page names the other sources with an ad_id variable that are not marked, since their clicks no longer share that spend.
app: Changed: ChatGPT Ads spend goes only to clicks from your ChatGPT Ads traffic sources, so another source's clicks with the same ad id keep their own cost. If you set up a ChatGPT Ads source yourself, mark it as ChatGPT Ads on its edit form in Traffic Sources.
