-- New: ChatGPT Ads campaign control through an ad connection. Setup › Destinations › ChatGPT Ads › campaigns, `/api/v3/ad-connections/{id}/campaigns`, `/ad-groups`, `/ads` and `/spend`, and `p202 ad-campaign list|get|pause|activate|set-template|attach-events|spend` list campaigns, ad groups and ads as OpenAI has them now: status, budget, review status and serving issues. From the same places you can pause and activate each one, and set the tracking template OpenAI appends to the ad's URL (by default the one Get Links gives for the ChatGPT Ads source). You can also add conversion event settings to a campaign while keeping the ones it has. Spend, impressions and clicks are shown by campaign over whole days in the ad account's time zone. Every write can be previewed with ?dry_run=1 / --dry-run, which sends nothing; the page asks before it pauses or activates. When OpenAI fails, the API answers 404 (no such object), 429 (its rate limit) or 502 (no answer), with OpenAI's own words. The local MCP server (`p202 mcp`) gains ad_campaign_list, ad_campaign_pause, ad_campaign_activate, ad_campaign_spend and destination_list.
